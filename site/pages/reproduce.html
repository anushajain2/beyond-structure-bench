Methods and reproduction

Read it, reanalyse it, or run it

Three routes, depending on how far you want to check. Every published number comes from committed files in the v1.0.0 release.

Read

  • The evidence explorer shows any material and property.
  • Merged tables: lattice.csv, bulk_modulus.csv, thermal_expansion.csv, coverage.csv, and everything at once in summary.json.
  • Raw results per model and step in results/raw/; the six-case study's phonon data in results/thermal_failure/.
  • Experimental references, each with its source, citation and a short quote, in data/experimental/.

Reanalyse

Rebuild every table, statistic and figure from the committed raw results, with no new calculations:

git clone https://github.com/anushajain2/chipff-bench && cd chipff-bench
uv venv --python 3.12 && uv pip install -e ".[dev]"
chipff analyze      # results/*.csv, summary.json, bootstrap statistics
chipff report       # figures and report/index.html
python scripts/build_site.py   # this website, into _site/

To use exactly the package versions the results were computed with, install from env/requirements-lock.txt first.

Run

Start with one available model on one material. This recomputes the stored silicon results for MACE-MPA-0; they should agree with the committed ones to about 0.2 %. It takes about two minutes on an Apple-silicon laptop CPU. The Materials Project structures are committed, so no API key is needed.

chipff static -m mace-mpa-0 --materials Si --force   # lattice, elastic tensor, equation of state
chipff qha    -m mace-mpa-0 --materials Si --force   # thermal expansion, quasi-harmonic
chipff analyze

kUPS logs "Fixing failed assertions" while it enlarges its neighbour-list buffers; that is expected. To check that the model files match the ones the results used, run python scripts/verify_checkpoints.py.

The full pipeline, measured on the same laptop CPU: static properties take about an hour for each kUPS model, and thermal expansion about 45 minutes for MACE-MPA-0 and 15 minutes for MatterSim. MatterSim runs through its official package in a separate environment (env/requirements-mattersim-lock.txt), with PYTHONPATH=src .venv-mattersim/bin/python -m chipff.cli static -m mattersim-5m-native. The six-case study reruns with python scripts/thermal_failure_study.py, about 45 minutes. UMA needs Meta's licence on Hugging Face and is not part of this release.

Methods in brief

PropertyHow it is computedReferences
Lattice constantAtoms and cell relaxed together from the Materials Project structure (L-BFGS with a Fréchet cell filter, forces below 0.001 eV/Å). Error: effective linear error (V/Vref)1/3 − 1.Materials Project PBE structure; room-temperature diffraction
Bulk modulusFull elastic tensor from 24 strains (each Voigt component at ±0.5 % and ±1 %), ions relaxed, giving KVoigt, KReuss and KVRH; a Birch–Murnaghan equation of state as a cross-check.Materials Project PBE elastic tensor; ultrasonic, Brillouin or compression measurements, compared like for like
Thermal expansionQuasi-harmonic approximation: phonons (phonopy, finite displacements of 0.01 Å, supercells at least 10 Å across) at nine volumes from 0.96 to 1.08 V0, Vinet fit of the free energy, Γ-point acoustic modes excluded. Compared at 300 K and averaged over a pre-registered temperature window.Dilatometry and diffraction compilations, averaged over the same window

Every setting, threshold and dated amendment is in configs/benchmark.yaml. Fuller detail: findings, methods and limits, statistics, why quasi-harmonic and not MD, result fingerprints and the six-case study.

Exact versions

  • kups 1.0.8, jax 0.11.2, phonopy 4.8.3, Python 3.12; MatterSim through mattersim 1.2.5 and torch 2.14.1. Full lists: env/requirements-lock.txt and env/requirements-mattersim-lock.txt.
  • Model files: MACE-MPA-0 medium (CuspAI export CuspAI/kUPS-mace-jax, revision aa54c05), Orb v3 conservative OMat (CuspAI/kUPS-orb-jax, revision 33127c6) and MatterSim v1 5M (Microsoft's checkpoint). SHA-256 checksums for each are in configs/checkpoints.json.

Sources

  • Toolkit: kUPS (CuspAI), with phonopy, pymatgen and ASE.
  • Structures and DFT references: Materials Project, with the ID of each material recorded.
  • Experimental values: one cited source per value. Main compilations: the Ioffe semiconductor database, NBS Circular 539 (lattice parameters), Touloukian et al., TPRC Data Series vols 12–13 (thermal expansion), and Kaye & Laby (metals), plus primary papers for bulk moduli and layered materials.
  • Related benchmarks: CHIPS-FF (Wines and Choudhary) and UniFFBench (Mannan et al.). The full reference list, each entry checked against its publisher or arXiv record, is in docs/references_verified.json.
